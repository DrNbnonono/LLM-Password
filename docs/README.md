# Docs 目录说明

这个目录用于存放研究文档，而不是代码或原始数据。

建议逐步补齐以下文件：

- `todo.md`
  - 当前项目拆解与后续任务清单。

- `model-list.md`
  - 模型标准命名、来源、类型、版本、调用方式。

- `prompt-design.md`
  - 提示模板、实验目的、风险说明、版本记录。

- `dataset-spec.md`
  - 数据字段说明、清洗规则、划分策略。

- `experiment-plan.md`
  - 后续实验路线图。

## 使用建议

- 文档优先写“为什么这样做”和“具体怎么复现”。
- 命名保持稳定，方便后续交叉引用。
- 论文、README、脚本说明中出现的重要名词，尽量在这里保持统一解释。
